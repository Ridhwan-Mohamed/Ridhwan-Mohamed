I’m a graphics programmer interested in **real-time rendering, GPU programming, engine systems, geospatial visualization, simulation, and game technology**.

I enjoy building visual systems from the ground up, exploring how data moves through the CPU and GPU, and creating **compelling, efficient real-time graphics**.

### What I've built / am working on

🗺️ **[D3D12 Real-Time LiDAR Renderer](https://github.com/Ridhwan-Mohamed/D3D12-Realtime-LiDAR-Renderer)**  
A from-scratch C++20 and Direct3D 12 point-cloud renderer for exploring large LAS, LAZ, and COPC geospatial datasets. Features spatial level of detail, frustum culling, GPU memory budgeting, tile residency, classification and elevation visualization, GPU timing, and fence-safe resource management.

🌌 **[Gravity Forge — DirectX 12 Galaxy Renderer](https://github.com/Ridhwan-Mohamed/DirectX12-Galaxy-Generator)**  
A real-time GPU particle simulation and renderer built with C++20, Direct3D 12, and HLSL. Explores compute shaders, GPU-driven visibility and culling, HDR rendering, bloom, frame resources, synchronization, and rendering architecture.

🏰 **[Permit Approved](https://github.com/Ridhwan-Mohamed/Permit-Approved)**  
A Phaser-based RTS and colony-simulation game with real-time unit movement, construction, resource gathering, combat, dynamic pathfinding, and settlement systems.

🧭 **Phaser Navmesh Acceleration**  
Experiments with runtime navigation-mesh mutation, localized polygon patching, and bounded rebuilds intended to avoid rebuilding the complete navmesh after changes to the world.

🖥️ **[3DFX.js](https://github.com/Ridhwan-Mohamed/3DFX.js)**  
A software 3D renderer built from scratch in JavaScript. Implements triangle rasterization, clipping, UV texturing, depth buffering, backface culling, matrix transformations, and 3MF model loading without WebGL or an external graphics API.
